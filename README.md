# FluffLabs VPM Listing

FluffLabs が配布する VRChat 向けパッケージの VPM リポジトリです。

VRChat Creator Companion（VCC）の Settings → Packages → Add Repository で、次の URL を追加してください。

```
https://fluffite.github.io/vpm/index.json
```

## 収録パッケージ

- [Kurena-chan's A to T Adapter](https://github.com/fluffite/kurena-a2t)（`net.fluffium.kurena-a2t`）
